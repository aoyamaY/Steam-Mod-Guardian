# Security / 安全反馈

Report suspected vulnerabilities in this tool privately to the repository maintainer using GitHub private vulnerability reporting if enabled. If unavailable, request a private channel without posting exploit details publicly. Do not attach actual malicious binaries, credentials, account information, or unredacted logs to public issues. Share only hashes and redacted evidence initially.

This project provides risk indicators, not a malware verdict or sandbox. Do not disable security software, run suspicious mods to test them, or restore quarantined items unless independently verified. Steam may redownload files. External analyzers must come from trusted sources and are not sandboxed. No protection is guaranteed. Report false positives with the file hash, rule names and sanitized evidence.

请优先通过仓库的私有漏洞报告功能（若已启用）反馈漏洞；未启用时先请求私下沟通渠道。公开 Issue 不要上传真实木马、凭据、私人路径或完整日志。可先提供 SHA-256、规则名及脱敏证据。静态结果不等于恶意定论，不要为测试运行可疑模组，不要关闭系统防护。
