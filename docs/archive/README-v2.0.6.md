# Steam Mod Guardian 2.0.6

通用 Steam 模组静态安全检测、更新审查和可选运行时观察工具。基于 v1.4.0 源码升级。**不是杀毒软件、沙箱或强制加载拦截器。未发现风险不代表安全。** 不运行待扫描脚本、程序集或原生二进制。默认不需要管理员权限。

## 构建 / 安装

1. Windows x64，安装 .NET 8 SDK（https://dotnet.microsoft.com/download/dotnet/8.0）。
2. 在新目录解压，双击 `build.bat`。脚本执行无害测试、发布自包含 WPF 应用、实际窗口渲染检查及可选 TCP 表读取检查。
3. 运行 `publish-v2.0.6\DuckovModGuardian.exe`，保留整个发布目录。
4. UI smoke test 必须通过；TCP smoke test 失败时会提示警告，静态扫描仍可使用。启动失败可运行 `diagnose.bat`，查看 `%LOCALAPPDATA%\DuckovModGuardian\startup.log`。

**本交付为源码。** 生成环境没有 Windows/WPF/.NET SDK，未执行编译、测试或真实网络 API；已检查 XML、事件名、DataTrigger 绑定、ZIP 完整性。请以 Windows 上实际测试结果为准。`README-v1.4.md` 是保留的旧版参考；旧版命令与功能说明以本文件为准。

## v2.0.2 · 新手模式和统一界面

- 主窗口、游戏选择、隔离库、VirusTotal、运行时观察、入门向导、应用内确认/提示均使用自绘标题栏和共享半透明玻璃风格。支持拖动、关闭、适用窗口的调整大小和最大化/还原。系统文件选择框及启动崩溃兜底仍保留 Windows 原生样式。
- 玻璃效果通过应用内半透明渐变、细边框、圆角模拟，不使用 DWM 桌面实时背景模糊；不依赖 Windows 11 特有的合成效果。
- 首次打开本版本自动显示三步向导，支持跳过或通过顶部「使用指南」重新打开。新用户在线标题查询默认关闭，向导可明确勾选；已有用户继续使用已保存的设置。
- 「一键推荐扫描」使用当前配置范围；没有范围时先确认选择有已知目录的游戏。开启正常缓存，不自动隔离、恢复、上传文件、启动游戏或开启第三方检测。其他游戏的本地 Mod 目录需要手动添加。
- 游戏卡片列表显示名称、AppID、安装状态和目录状态，支持搜索、仅显示有目录游戏、选择当前显示及清空选择。高级目录和检测设置默认折叠。
- 中栏只读结果表、快速高危/文件下载过滤、清空搜索、自动选中首项、无结果提示、风险及下载行为高亮；右栏有对应的风险解释和原始证据。
- 自定义下拉框使用标准 `PART_Popup` 及双向展开绑定，滚动条按水平和垂直方向分别绑定。新增 UI smoke test 使用虚构数据，检查筛选、风险解释、空状态、下拉菜单、横向滚动条和自绘窗口；不访问网络或扫描真实文件。
- 运行时观察、隔离库、更新记录、配置目录及高级工具入口在左侧。所有检测、隔离、恢复、社区名单和持久化功能保留；数据目录与之前版本相同。
- 风险说明：绿色只是未发现线索，黄色需复核，紫色未知或未完成，红色高危线索需要优先人工核对。下载能力不代表实际发生过下载；不应仅凭静态结果删除 Mod。

## v1.5–v2.0 功能

|版本|实现|边界|
|---|---|---|
|1.5|Lua、Python、JS/TS、PowerShell、Shell、GDScript 等文本行为规则、行号、下载分类|启发式关键字/调用形式；注释、字符串可能误报，不构建完整 AST 或数据流；UTF-8/UTF-16；文本上限 8 MiB|
|1.6|Windows PE32/PE32+ 原生 DLL/EXE、普通导入表、库/函数摘要、节权限、混合模式 PE|不做反汇编/动态分析，不解析延迟导入、打包壳或全部间接 API；不能确认调用关系；无法解析标未知|
|1.7|提取 ASCII/UTF-16 HTTP(S) 主机名，域名/IP 本地名单、国际化域名/IP 提示|不访问这些地址，不记录完整 URL、查询参数或凭据；编码或运行时拼接地址可能漏检；默认空名单|
|1.8|VirusTotal v3 所选文件 SHA-256 / 域名信誉查询|需用户 API Key 和明确点击发送；不上传文件；展示引擎统计及分析时间，不直接替代本地风险等级；Key 不持久化；受额度/网络限制|
|1.9|每个游戏额外路径、选中游戏、标题查询、监控设置、按扫描目录集合保存基线及最多 500 条变化记录|监控只在应用运行时每 60 秒检查；关闭应用不会运行后台服务；扫描范围变化时使用独立基线；不会记录程序关闭期间事件的准确发生时间|
|2.0|指定进程 TCP IPv4/IPv6 远端端点采样、观察新加载模块、IP 名单提示及本地日志导出|每 2 秒采样；不抓包、不读取通信内容、不追踪子进程、不覆盖 UDP/DNS 或短连接；不能定位到具体 Mod；不拦截、自动隔离或杀进程|

### 静态规则说明

- 保留 Mono.Cecil IL 检测、调用关联、文件哈希、归一化指纹、YARA 和签名社区名单。
- 直接文件下载 API、疑似下载落盘、联网与写入共现单独标识。脚本/原生规则基于能力和共现，不是实际数据流证明。
- 脚本、托管、原生及未支持的二进制均展示类型。原生 PE 即便没有高风险证据也需要复核。`.so`、`.dylib`、`.luac`、`.pyc`、`.jar` 暂列未知，不宣称深度解析。通用资源/压缩包（如 PAK、VPK、ZIP）内部暂不扫描；扩展名伪装文件可能漏检。文件上限 64 MiB。
- 安全启动只覆盖所配置范围；高危、未知、扫描警告会阻止本工具启动，不能阻止直接 Steam 启动或启动后的文件变化。

### 每游戏配置和监控

选择一个游戏再添加本地 Mod 目录，该额外路径归该游戏；多选时新增未关联目录保存为全局路径。选择游戏会保存旧配置并切换到所选游戏的自动目录、专属额外目录和全局目录。开始扫描或点击“保存当前游戏配置”保存当前设置。已保存的监控开关在下次启动后恢复。监控会重新识别所选游戏的工坊目录并扫描，可能产生磁盘负载；不使用时请关闭。

本地数据仍使用 `%LOCALAPPDATA%\DuckovModGuardian` 以兼容旧版隔离库和规则，新增 `profile-v2.json`、`baseline-<scope sha256>.json` 和 `domains.txt`。历史只保存精简文件记录及最多 500 条变化，不保存 API Key。规则版本更新后旧 IL 缓存自动失效。

### 信誉与运行时观察

点击“本地域名名单”，每行填入经核实的域名或 IP，`#` 为注释。子域名匹配所属域名；IP 精确匹配。重新扫描后生效。默认没有已知恶意域名；本地名单并非公共威胁情报服务。

选中扫描结果，点击 VirusTotal 信誉查询，输入自己的 API Key，选择哈希或域名并发送。只调用官方 HTTPS API，不上传文件，也不请求 Mod 中提取的地址。404/429/错误不算安全，在线结果不参与自动隔离或强制启动决策。

先正常启动可信游戏，再打开“运行时观察”，选择目标进程、点击开始。首次端点为基线，后续新端点及模块为待复核线索；命中已配置 IP 名单单独提示。PID 与进程启动时间用于防止 PID 重用。停止/关闭即停止采样。日志保留在窗口内，可手动导出（可能含本地路径和网络地址，请检查后分享）。进程权限不足时明确提示模块列表不可读。

### 旧功能配置

- YARA：从官方发行版下载可信 Windows 引擎，选择独立安装的 exe 与规则（`rules/guardian.yar`）；默认不启用。不使用模组目录中的可执行程序。规则命中是线索。
- 社区名单：兼容 v1.4 的 HTTPS + RSA-SHA256 签名机制，需可信公钥和名单 URL；没有默认公共服务器或未经核实的木马名单。
- 隔离：先停止游戏和 Steam 更新，核对 SHA-256，文件移入隔离库。恢复不覆盖现有文件。Steam 可能重新下载，确认恶意后应取消订阅及举报。

## v2.0.3 · 原生 Acrylic 和增强检测

- Windows 11 22H2（build 22621）起尝试官方 DWM Desktop Acrylic（DWMWA_SYSTEMBACKDROP_TYPE=TRANSIENTWINDOW）；保留普通 HWND 与 WindowChrome，使用透明 WPF 合成背景。主窗口、应用内弹窗使用圆角外框，Windows 11 请求系统圆角，旧系统使用圆角窗口区域回退。最大化时为矩形。
- 实际玻璃由 DWM 决定，受系统透明效果、节能、高对比度、远程桌面及显卡环境影响。兼容模式使用深色不透明背景。底部显示外观状态（表示 API 请求结果，不表示已验证视觉效果）。下拉菜单使用半透明色，不是独立 DWM Acrylic 窗口。系统文件选择器和崩溃兜底仍由 Windows 绘制。
- Windows AMSI：勾选“增强检测：Windows 防病毒引擎”并确认后，在当前运行会话扫描文件字节，使用系统注册的安全提供程序（不保证为 Defender）。提供程序可能依据自身策略云查询、提交样本或采取防护措施。本程序不直接上传、不启动样本、不修改杀毒配置。16 MiB 上限；同步提供程序调用可能较慢，取消在调用返回后生效。失败、管理策略阻止、检出分别显示；未检出不降低已有风险。外部引擎结果不写入静态分析缓存。
- ZIP/JAR 和 .bin/.dat/.bytes 中有 PE/ZIP 文件头的内容，以及托管 DLL 嵌入资源的有限静态分析。最多 512 归档条目、256 资源、32 MiB 内部扫描预算、单成员 8 MiB、归档压缩比 200；不解压到磁盘，不递归扫描嵌套归档；不支持 Java 字节码等将报告不完整。不是通用脱壳器，不能识别所有加密/动态内容。
- IL 调用关系增加本地成员引用和 async/iterator 状态机连接，仍属调用相关性分析，而非完整污点传播或运行时沙箱。检测结果按证据融合，不将多个弱特征虚构成恶意概率。
- 测试包含合成归档、合成 IL 资源、AMSI 返回码映射和 UI 状态，不调用实际杀毒提供程序或运行样本。Windows 实机验证请运行 build.bat；若外观无模糊，检查 Windows 设置→个性化→颜色→透明效果。

## v2.0.4 · 外框与引擎配置

- 主窗和应用内弹窗仅移除最外层描边；Windows 11 DWM 外边框也请求关闭。保留圆角、Acrylic 与内部控件样式。
- AMSI 启用前自检初始化；0x80070103 对应 ERROR_NO_MORE_ITEMS，不能仅据此确认杀毒软件被关闭。自检失败时不会启用 AMSI，并明确提示静态扫描仍可用。扫描中初始化失败则保留检测不完整警告和已有风险。未修改 Defender 或系统安全设置。
- PowerShell 查看 Defender 状态：`Get-MpComputerStatus | Select-Object AMRunningMode,AMServiceEnabled,AntivirusEnabled,RealTimeProtectionEnabled`。如果使用第三方防病毒软件，请检查其状态与 AMSI 支持情况。
- YARA：从 https://github.com/VirusTotal/yara/releases 下载 Windows x64 ZIP，完整解压到独立可信目录，选择 yara64.exe。默认推荐发布目录中的 rules/guardian.yar；也可选择其他可信源规则。用无害文本测试 CLI 和规则是否可用，失败不会启用；不验证实际检出率。配置仅本次程序运行有效。
- 本版未在 Windows 实机验证；build.bat 包含 UI 测试及不调用实际杀毒引擎的合成测试。

## v2.0.6 · 一键 YARA 与严格下载风险

- 主界面左侧点击「一键下载并启用 YARA」，自动查询 VirusTotal/yara 官方 GitHub 最新稳定版 Windows x64 ZIP，仅在官方资产元数据有 SHA-256 时下载并验证。校验不符、非可信重定向、缺少摘要或自检失败均不启用新引擎。摘要来自 GitHub 发布元数据，不是独立代码签名。
- 解包到 `%LOCALAPPDATA%\DuckovModGuardian\tools\yara` 下独立随机目录；仅解包 yara64.exe 与同目录 DLL 依赖，不执行其他归档内容。使用内置 rules/guardian.yar 和无害阳性自检规则。不会上传 Mod，不需要管理员权限。
- 关闭窗口会取消安装；自动配置失败保留原配置。安装文件保留，但 YARA 启用状态仅本次运行有效。下次点击一键配置会重新检查官方版本并下载，离线可通过手动配置选择已安装引擎。
- 直接文件下载 API、疑似下载落盘统一升级为极高风险（包括嵌入载荷、归档、脚本、原生 PE 和托管 DLL）；仅联网、仅接收内存数据、仅联网与文件写入共现则维持原规则评级。严格策略可能误报合法更新器和资源下载功能；不代表已下载或确认恶意。
- 更新规则版本，旧 IL 缓存自动失效；高危过滤、隔离和安全启动复查使用新风险等级。不会自动隔离或删除。
- 构建测试含无害 ZIP、元数据、摘要、路径验证及下载风险测试，不联网、不执行测试载荷。实际自动安装需要 Windows 和 GitHub 网络连接。
