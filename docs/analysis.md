# Local analysis design / 本地分析设计

The core scanner never loads a target DLL into the runtime. Mono.Cecil parses metadata and IL. `LocalFlow` explores normal control-flow successors with a bounded worklist, merges abstract locals/operand stacks, and tracks selected network return values to selected file/assembly sinks. Merging is may-analysis and can overapproximate feasible paths. Exception-handler methods, complex field/alias and cross-method data flow are not modeled; existing call-graph heuristics still run. Constant evaluation handles only a few pure string operations; no decoded content is executed. Domain evidence includes host names only. `IlSimilarity` uses normalized token 4-grams and 64-bit SimHash with bounded band buckets and Hamming distance; similarity is neither TLSH nor a malware signature. Legacy critical download rating intentionally remains conservative. 

`LocalTools` uses explicitly selected trusted CLI programs with bounded output, timeouts, argument arrays, and hash-verified temporary copies for capa/FLOSS/TLSH. Tools are not contained in a sandbox. YARA-X uses NDJSON output and a harmless positive configuration test. ETW uses TraceEvent with a uniquely named temporary kernel session, selected-PID aggregation, no event payload retention, and a 60-second limit. Kernel events are system-wide at collection; application filtering occurs before retaining counts. Permissions, missing events, PID reuse and provider availability can affect results. No child-process attribution or Mod attribution is guaranteed.

核心扫描不执行待检代码。污点分析是有限方法内的 may-analysis，分支合并可能过近似；异常处理、跨方法传播、复杂字段别名与完整异步追踪未实现。字符串仅进行有限静态还原，结果不执行。SimHash 为近似方法结构线索，不等于 TLSH 或木马签名。专业 CLI 与 ETW 均为本地辅助功能，不构成沙箱；ETW 仅统计指定 PID，可能漏事件，不能归因到具体 Mod。
